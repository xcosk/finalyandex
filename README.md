# Планировщик задач (TODO)

Веб-сервер на Go

Что делает приложение:
- добавляет задачи;
- возвращает список ближайших задач;
- возвращает одну задачу по `id`;
- редактирует задачу;
- отмечает задачу выполненной;
- удаляет задачу;
- поддерживает повторяемые задачи по базовым правилам `d N` и `y`.

## Выполненные задания со звездочкой
- Шаг 1: поддержка `TODO_PORT`.
- Шаг 2: поддержка `TODO_DBFILE`.
- Шаг 8: аутентификация по `TODO_PASSWORD` и `/api/signin`.
- Docker: добавлен `Dockerfile`.

## Что не реализовано
- Расширенные правила повторения `w ...` и `m ...`.
- Поиск в `/api/tasks?search=...`.

## Локальный запуск
Требования: Go 1.22+.

1. Установить зависимости:
```bash
go mod download
```

2. Запустить сервер:
```bash
go run main.go
```

Опциональные переменные окружения:
- `TODO_PORT` — порт сервера (по умолчанию `7540`);
- `TODO_DBFILE` — путь к SQLite-файлу (по умолчанию `scheduler.db`);
- `TODO_PASSWORD` — если задан, включается аутентификация API.

Адрес в браузере:
- `http://localhost:7540/`.

Аутентификация:
- сначала откройте `http://localhost:7540/login.html`;
- фронтенд отправит `POST /api/signin` и сохранит `token` в cookie.

## Docker
Сборка образа:
```bash
docker build -t finalyandex:latest .
```

Пример запуска с БД на хосте:
```bash
docker run --rm -p 7540:7540 \
  -e TODO_PORT=7540 \
  -e TODO_DBFILE=/data/scheduler.db \
  -v "$(pwd)":/data \
  finalyandex:latest
```

После запуска откройте `http://localhost:7540/`.
